Instructions

  1. Timer పైన కుడివైపు ఉంటుంది. Time అయిపోగానే paper దానంతట అదే submit అవుతుంది.
  2. Option select చేసాక Save & Next నొక్కితేనే answer save అవుతుంది.
  3. Mark for Review చేసిన question ని తర్వాత మళ్లీ చూడొచ్చు. Answer ఇచ్చి mark చేసినా ఆ answer evaluate అవుతుంది.
  4. Numerical questions కి answer ని keypad తో టైప్ చేయాలి (integer).
  5. Marking: సరైనదానికి +4, తప్పుకు −1, వదిలేస్తే 0.
  6. మధ్యలో power పోయినా, app close అయినా, అప్పటివరకు ఇచ్చిన answers పోవు. మళ్లీ open చేస్తే అక్కడి నుంచే continue అవుతుంది.
  7. Submit చేయగానే answers నాన్నకి వెళ్తాయి. సాయంత్రం 6 గంటలకు report వస్తుంది.
